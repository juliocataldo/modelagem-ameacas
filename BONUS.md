# Bônus: conteúdo de apoio

Material **opcional e sem nota** para aprofundar. Não confunda com o bônus de pontos do trabalho (o modelo no Threat Dragon, descrito no `README.md`).

- A maior parte do conteúdo está **em inglês**.
- Fonte da lista: [awesome-threat-modelling](https://github.com/hysnsec/awesome-threat-modelling) (hysnsec), mantida pela comunidade.
- Os links foram testados em 27/10/2026. Alguns sites bloqueiam testes automáticos e podem pedir cookies ou login. Se um link não abrir, avise o professor.
- Pode haver ferramentas e conteúdos desatualizados. Avalie a manutenção antes de usar algo em projeto real.

## Ferramentas

- [OWASP Threat Dragon](https://owasp.org/www-project-threat-dragon/): Aplicação web de modelagem de ameaças com diagrama do sistema e um motor de regras que sugere ameaças e mitigações. Também existe versão desktop. É a ferramenta do bônus de pontos do trabalho (app em [threatdragon.com](https://www.threatdragon.com)).
- [Microsoft Threat Modeling Tool](https://docs.microsoft.com/en-gb/azure/security/develop/threat-modeling-tool): Ferramenta da Microsoft para encontrar ameaças na fase de design do software (versão 2016, a mais antiga desta lista).
- [Owasp-threat-dragon-gitlab](https://github.com/appsecco/owasp-threat-dragon-gitlab): Fork do Threat Dragon com integração ao GitLab no lugar do GitHub.
- [Raindance](https://github.com/devsecops/raindance): Projeto para tornar os *attack maps* parte do desenvolvimento, reduzindo o tempo para fazê-los.
- [Threatspec](https://threatspec.org/): Projeto open source que aproxima segurança e desenvolvimento, levando a modelagem de ameaças para dentro do processo de desenvolvimento.
- [PyTM](https://github.com/izar/pytm): Biblioteca para modelar ameaças **como código**: você descreve o sistema com sintaxe orientada a objetos e o relatório sai automaticamente (100+ ameaças suportadas). Exige conhecer Python.
- [MAL](https://github.com/mal-lang): Projeto open source para criar sistemas de modelagem de ameaças cibernéticas e simulações de ataque.
- [Threagile](https://github.com/Threagile/threagile): Toolkit open source para modelagem de ameaças ágil.
- [TicTaaC](https://github.com/rusakovichma/TicTaaC): Modelagem de ameaças como código, leve e alinhada aos princípios de DevSecOps.
- [Threat Modeling Online Game](https://github.com/dehydr8/elevation-of-privilege): Versão online dos jogos de cartas *Elevation of Privilege* e *Cornucopia*. Um jeito fácil de começar.
- [Deciduous](https://www.deciduous.app/): Aplicação web que simplifica a construção de árvores de decisão de ataque.
- [drawio-threatmodeling](https://github.com/michenriksen/drawio-threatmodeling): Coleção de bibliotecas para o Draw.io (gratuito e multiplataforma) virar uma ferramenta de modelagem de ameaças.
